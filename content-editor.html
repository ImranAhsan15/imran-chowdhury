Local editing helper

Update the portfolio without coding

This page is not linked from the public navigation. Edit the common content below, download the updated site-data.js, and replace the old file inside assets/js/.

Open website preview Current website content loaded.
Images: copy your JPG, PNG, WebP, or SVG into assets/uploads/images/. Then enter a path such as assets/uploads/images/drone-training.jpg.
Videos: upload large videos to YouTube or Vimeo and paste the public URL. Do not upload large video files to GitHub.

1. Basic profile

These values appear on the homepage, About page, CV, and footer.

2. Academic profile links

Leave a field empty when you do not have a verified public profile.

3. Training you delivered

Use this for the ArcGIS Pro Essential Workflows training, drone-operation instruction, workshops, and future sessions where you were the trainer or evaluator.

4. Courses and training you completed

Use this for Esri Academy courses, certificates, university short courses, and your own professional development.

5. Write-ups

Add research summaries, project notes, downloadable reports, or links to internal website pages.

6. Pictures, maps, and figures

Enter the exact file path after copying the image into assets/uploads/images/.

7. Video demonstrations

YouTube and Vimeo URLs are converted automatically into embedded videos.

Finish the update

  1. Click Download updated site-data.js.
  2. Open your website folder and go to assets/js/.
  3. Delete or rename the old site-data.js.
  4. Move the newly downloaded file into that folder.
  5. Open index.html or run PREVIEW_WEBSITE.bat to check the result.
  6. Upload the changed files to the same GitHub repository.

The editor changes content only. It does not automatically upload files to GitHub.
